# MFA and SSO Sign-In Support

Northstar uses SSO with multi-factor authentication for VPN, email, payroll, and internal applications. MFA prompts may fail if the mobile device has poor connectivity, the authenticator app registration expired, or the device clock is out of sync.

Troubleshooting steps:
- Confirm the phone has data connectivity and notifications enabled.
- Open the authenticator app and use a one-time code if push notifications do not arrive.
- Verify the device time is set automatically.
- Try a registered backup method such as hardware key or SMS if configured.

Escalate to IT if no registered factor is available or if the account shows suspicious activity.
