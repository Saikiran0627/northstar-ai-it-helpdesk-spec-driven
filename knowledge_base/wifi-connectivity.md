# Corporate Wi-Fi Connectivity

Northstar-Secure is the preferred wireless network in offices. Guests should use Northstar-Guest and cannot access internal systems.

For employee Wi-Fi issues, forget and rejoin Northstar-Secure, confirm the certificate prompt references Northstar Technologies, and restart the wireless adapter. If only one area is affected, note the office, floor, and conference room.

Create a support ticket when multiple employees in the same location lose Wi-Fi or when certificate warnings appear.
