# VPN Remote Access Troubleshooting

Northstar employees working remotely should use the Northstar Secure VPN client. If the VPN disconnects repeatedly, first verify that the local internet connection is stable and that the employee completed MFA successfully.

Recommended quick actions for urgent meetings:
- Reconnect using the West gateway if the default gateway is unstable.
- Move from weak Wi-Fi to wired Ethernet or a mobile hotspot.
- Close high-bandwidth personal streaming or backup applications.
- Keep the presentation available offline when possible.

If disconnections continue after two reconnect attempts, collect VPN client logs and open a high-priority support ticket with the employee location, gateway, device type, and time of failure.
